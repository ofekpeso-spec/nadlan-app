# Nadlan IL – מחירי דירות בתוך Claude ו־ChatGPT

אפליקציה (שרת MCP) שמאפשרת לשאול את Claude או את ChatGPT שאלות כמו:

- "כמה נמכרו דירות 4 חדרים ליד הרצל 10 בתל אביב בשנתיים האחרונות?"
- "מה המחיר הממוצע למ"ר בשכונה הזו, ואיך הוא השתנה בשנה האחרונה?"
- "כמה בערך שווה דירה של 90 מ"ר עם 4 חדרים ברחוב X?"

הנתונים מגיעים **רק** מעסקאות רשמיות שדווחו לרשות המסים (מידע ציבורי דרך govmap.gov.il / nadlan.gov.il). אין איסוף מידע מאתרים פרטיים.

## מה יש באפליקציה (4 כלים)

| כלי | מה הוא עושה |
|---|---|
| `search_address` | מוצא כתובת ומחזיר התאמות |
| `recent_deals` | עסקאות אחרונות סביב כתובת, עם סינון לפי מספר חדרים ותקופה |
| `area_price_summary` | מחיר חציוני, מחיר למ"ר (טווח) ומגמה ב־12 החודשים האחרונים |
| `estimate_apartment_value` | הערכת שווי גסה (נמוך/אמצע/גבוה) לפי עסקאות דומות. **לא שומה** |

## ⚠️ צעד ראשון חובה: בדיקה מול השרת האמיתי

הקוד נבדק עם נתונים לדוגמה, אבל **לא מול השרת של govmap**, כי לסביבה שבה נבנה אין גישה לאינטרנט. ל־govmap אין תיעוד רשמי, ולכן ייתכן שצריך להתאים שמות שדות.

על מחשב עם אינטרנט ו־Python 3.11 ומעלה:

```bash
pip install -r requirements.txt
python -m nadlan_app.smoke_test "הרצל 10 תל אביב"
```

- אם יוצא `OK`, אפשר להמשיך.
- אם יוצא `FAIL`, שלח לי את הפלט ואני אתקן (בדרך כלל מדובר בשינוי של שורה או שתיים).

הרצת הטסטים: `python -m pytest -q tests`

## העלאה לאוויר (Render, הכי פשוט)

1. פותחים חשבון ב־GitHub ומעלים אליו את התיקייה הזו כמאגר (repo).
2. פותחים חשבון ב־render.com, בוחרים **New → Blueprint** ומחברים את המאגר. הקובץ `render.yaml` כבר מגדיר הכל.
3. אחרי כמה דקות מקבלים כתובת, למשל `https://nadlan-il.onrender.com`.
4. בודקים שהשרת עובד: `https://<הכתובת>/health` צריך להחזיר `{"status":"ok"}`.
   בדיקה מול govmap האמיתי, גם מהטלפון: `https://<הכתובת>/selftest`. אם רואים `"result":"OK"`, הכל עובד.
5. כתובת ה־MCP היא `https://<הכתובת>/mcp`.

> התוכנית החינמית של Render "נרדמת" כשאין שימוש, וזה גורם להשהיה בבקשה הראשונה. לאפליקציה ציבורית עדיף התוכנית הבסיסית בתשלום (כמה דולרים בחודש). בדוק את המחיר העדכני באתר.

## חיבור לבדיקה אישית (לפני הגשה)

- **Claude:** Settings → Connectors → Add custom connector, ומדביקים את כתובת ה־`/mcp`.
- **ChatGPT:** מפעילים Developer mode בהגדרות ומוסיפים אפליקציה עם כתובת ה־`/mcp`.

שואלים כמה שאלות אמיתיות ומוודאים שהתשובות הגיוניות.

## הגשה לחנויות

**Claude:** נכנסים ל־claude.ai/directory/manage, לוחצים Submit new ובוחרים MCP connector. נדרש מנוי Claude בתשלום. צריך להכין:
- קישור לתיעוד (אפשר את הקובץ הזה ב־GitHub)
- קישור למדיניות פרטיות (`PRIVACY.md`)
- כתובת ליצירת קשר לתמיכה
- אייקון

**ChatGPT:** מגישים דרך פלטפורמת המפתחים של OpenAI (Apps SDK) עם אותה כתובת `/mcp`, תיאור, מדיניות פרטיות ומדינות זמינות.
