# Nadlan IL – מידע לקוני דירות, בתוך Claude ו־ChatGPT

אפליקציה (שרת MCP) שעוזרת למי שקונה או שוכר דירה בישראל לבדוק אזור, **רק ממידע ממשלתי פתוח** (data.gov.il). אפשר לשאול למשל:

- "יש פינוי־בינוי ברחוב סוקולוב בחולון?"
- "כמה אתרי בנייה פעילים יש ליד הרצל בתל אביב?"
- "אילו הגרלות מחיר למשתכן היו בבאר שבע, ובאיזה מחיר למ"ר?"
- "תן לי סקירה כללית על השכונה לפני שאני קונה"

> מחירי עסקאות של דירות ספציפיות לא זמינים באפליקציה, כי govmap חוסם גישה אוטומטית אליהם (reCAPTCHA). האפליקציה מפנה את המשתמשים לאתר הרשמי nadlan.gov.il.

## הכלים

| כלי | מה הוא עושה |
|---|---|
| `area_report` | סקירה של עיר או רחוב בקריאה אחת |
| `urban_renewal_projects` | מתחמי פינוי־בינוי מוכרזים |
| `construction_sites` | אתרי בנייה פעילים |
| `subsidized_housing_lotteries` | הגרלות מחיר למשתכן / דירה בהנחה |
| `housing_pipeline` | היצע דיור מתוכנן |
| `find_open_datasets` / `query_open_dataset` | חיפוש בכל מאגרי data.gov.il (גנים, תחבורה ועוד) |

## כתובות

- שרת: `https://nadlan-il.onrender.com`
- בדיקת חיות: `/health`
- בדיקה מול הנתונים האמיתיים: `/selftest`, או `/selftest?city=חולון` (אפשר לפתוח מהטלפון)
- כתובת MCP לחיבור: `/mcp`

כל עדכון שנדחף ל־GitHub מתעדכן אוטומטית ב־Render.

## חיבור לבדיקה אישית

- **Claude:** Settings → Connectors → Add custom connector, ומדביקים את `https://nadlan-il.onrender.com/mcp`
- **ChatGPT:** מפעילים Developer mode בהגדרות ומוסיפים אפליקציה עם אותה כתובת

## הגשה לחנויות

**Claude:** נכנסים ל־claude.ai/directory/manage ← Submit new ← MCP connector. נדרש מנוי Claude בתשלום. צריך להכין: קישור לתיעוד (הדף הזה), קישור למדיניות פרטיות (`PRIVACY.md`), אימייל לתמיכה ואייקון.

**ChatGPT:** מגישים דרך פלטפורמת המפתחים של OpenAI עם אותה כתובת `/mcp`.

### טקסט לדף בחנות

**שם:** Nadlan IL – בדיקת אזור לקוני דירות

**תיאור קצר:** פינוי־בינוי, אתרי בנייה, הגרלות מחיר למשתכן והיצע דיור עתידי, לכל עיר ורחוב בישראל, ממאגרי המידע הרשמיים של המדינה.

**תיאור מלא:** לפני שקונים או שוכרים, כדאי לדעת מה קורה מסביב. שאלו בעברית או באנגלית על כל עיר או רחוב, וקבלו: האם הבניין או הרחוב נמצאים במתחם פינוי־בינוי, אילו אתרי בנייה פעילים יש בסביבה, אילו הגרלות מחיר למשתכן היו בעיר ובאיזה מחיר, וכמה דירות חדשות בדרך. כל הנתונים ממאגר המידע הממשלתי הפתוח data.gov.il.
